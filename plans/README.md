## What this audit established about production

Measured read-only on 2026-09-18 and relied on by plans 004 and 005:

- `ui.tanfust.com` is served by **Cloudflare Workers with static assets**
  (`server: cloudflare`), and `public/_headers` **is** being applied —
  `/r/*.json` and `/llms.txt` return `cf-cache-status: HIT` with
  `access-control-allow-origin: *` and `cache-control: public, max-age=300, s-maxage=3600`.
- The shadcn root negotiation **works**: `GET /` with
  `Accept: application/vnd.shadcn.v1+json` returns the catalog JSON.
- `/`, `/docs` and item pages return `text/html` with **no** `cache-control`
  and **no** `cf-cache-status` — every page view is an uncached Worker render.
- Nothing in this repository builds that deployment: `vite.config.ts` uses
  Nitro's default `node-server` preset, and there is no Wrangler config,
  `@cloudflare/vite-plugin`, or deploy job. The deploy configuration lives
  outside the repo.

## Findings considered and rejected

So nobody re-audits these:

- **`use-mobile`'s `innerWidth` / `matchMedia` mismatch** — `use-mobile.ts:17`
  compares `window.innerWidth < breakpoint` while subscribing to
  `(max-width: breakpoint - 1px)`, which disagree at fractional widths. This is
  inherited verbatim from shadcn's own `use-mobile`; changing it would diverge
  from the upstream every consumer expects, for a sub-pixel edge case.
- **The design-token duplication** between `src/styles.css` and the `tanfust` /
  `theme-tanfust` items — deliberate and documented. `AGENTS.md` names
  tanfust.com's `docs/design.md` and `docs/paper-theme.md` as the source of
  truth, and `src/styles.css` carries a comment saying the values are mirrored
  on purpose. Not a DRY violation to fix here.
- **Registry items' "redundant" defensive checks** — `eslint.config.js`
  explicitly disables `no-unnecessary-condition` and
  `no-unnecessary-type-assertion` for `src/registry/**` because those files ship
  into consumer projects with unknown tsconfig strictness. By design.
- **`@tanstack/react-router-ssr-query` is an unused dependency** — real, but
  too small to justify a plan on its own. Fold it into whichever plan next
  touches `package.json`; note that plan 001 removes the only reason it might
  have been added (`defaultPreloadStaleTime: 0` is the external-cache setting).
- **Duplicate section numbers on item pages** — `docs.$category.$item.tsx`
  reuses `"03"` for Source, Font and components.json, and `"06"` skips ahead.
  Cosmetic; fold into any future edit of that file.
- **`og:url` is the site root on every page; no canonical, no `og:image`** —
  a genuine SEO gap but outside the TanStack/Cloudflare scope of this audit.
  Worth its own pass if SEO becomes a priority.
- **`useStepper`'s `optional = []` default** breaking `skip`/`canSkip`
  memoisation every render — real but low impact. Deliberately noted in plan
  003's maintenance notes rather than fixed, because changing a shipped item is
  a breaking change for consumers and needs a `meta.version` bump.
